# Journal Entries

Journal entries record financial transactions using debit and credit accounts.

## Introduction

Every journal entry should have a transaction date, a meaningful description and balanced debit and credit amounts.

## Creating a Journal Entry

Follow these steps to create a journal entry.

### Basic Information

Enter the transaction date, reference number and description.

### Adding Accounts

Select the relevant debit and credit accounts, then enter the amounts.

### Verify the Entry

Make sure the total debit amount equals the total credit amount before saving.

## Editing a Journal Entry

Open the journal entry, choose **Edit**, update the required information and save your changes.

## Deleting a Journal Entry

Only delete entries when permitted by your organization's accounting policy. Posted transactions may require a reversal instead.
